# Universidad Java — De Cero a Experto

Bienvenido a mi repositorio de aprendizaje de **Java**.

Este repositorio contiene mis avances, ejercicios y proyectos desarrollados durante el curso **Universidad Java — De Cero a Experto** en Udemy.

## Sobre el curso

A lo largo del curso estoy fortaleciendo mis conocimientos en Java, comenzando desde los fundamentos del lenguaje y avanzando progresivamente hacia conceptos, herramientas y tecnologías utilizadas en el desarrollo profesional.

## Contenido del repositorio

Aquí iré almacenando ejercicios y proyectos relacionados con temas como:

* Fundamentos de Java
* Programación Orientada a Objetos (POO)
* Clases, objetos, herencia y polimorfismo
* Manejo de excepciones
* Colecciones y estructuras de datos
* Manejo de archivos
* Bases de datos y JDBC
* Maven
* Spring y Spring Boot
* JPA / Hibernate
* Desarrollo de aplicaciones
* Proyectos prácticos

> El contenido del repositorio irá creciendo conforme avance en el curso.

## Objetivo

Mi objetivo es consolidar mis conocimientos en **Java y desarrollo de software**, aplicando los conceptos aprendidos mediante ejercicios y proyectos prácticos que me permitan mejorar progresivamente como desarrollador.

## Tecnologías
